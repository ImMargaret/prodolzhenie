# ПРОДОЛЖЕНИЕ

Русскоязычный интерактивный сайт. Отдельная история с Воландом, Маргаритой и Бегемотом — художественная цифровая интерпретация по мотивам «Мастера и Маргариты». Написанные для сайта диалоги и ситуации не являются цитатами из романа.


## Страницы и сценарий

| Файл | Содержание |
| --- | --- |
| `index.html` | Вход, парящий объект, папки разделов |
| `archive.html` | Три персонажа, работающие фильтр и поиск |
| `woland.html` | Досье Воланда, сканирование, сценарный диалог |
| `margarita.html` | Досье Маргариты, сканирование, сценарный диалог |
| `behemoth.html` | Досье Бегемота, сканирование, сценарный диалог |
| `memories.html` | Головоломка из шести фрагментов, три воспоминания |
| `protocol.html` | Три последовательных выбора |
| `mirror.html` | Отражение с камерой либо абстрактное присутствие |
| `ending.html` | Персональный финал, скачивание капсулы JSON |
| `about.html` | Идея, маршрут и сведения о проекте |

Звук включается кнопкой в шапке или клавишей **M**. На главной **Пробел** открывает архив. **Esc** закрывает меню и диалог. Кнопка отключения анимации находится в меню; системное предпочтение reduced motion тоже учитывается.

На главной в браузере с WebGL доступна кнопка **«Объёмная модель»**. Она открывает настоящую процедурную 3D-модель; её можно вращать перетаскиванием. Исходный режим показывает подробный CGI-рендер с параллаксом. Если WebGL недоступен, остаётся анимированный рендер, и сайт продолжает работать.

В игре выберите два фрагмента или перетащите один на другой. Кнопка «Показать оригинал» даёт трёхсекундную подсказку. После восстановления нажмите «Сохранить фрагмент». Прогресс, решения и отметка присутствия сохраняются локально.

Камера запрашивается только по нажатию. Для неё используйте HTTPS (в том числе GitHub Pages) или localhost. Можно пройти весь сценарий без камеры. Видеопоток не записывается и не отправляется. Скачанная капсула содержит только выборы, названия найденных воспоминаний и отметку участия.



Анимации, звук, камера и WebGL работают в HTML-сайте. Фреймы Figma — редактируемые визуальные макеты со связями прототипа. При повторном запуске создаётся ещё один комплект.

## Изменение проекта

Весь контент находится в статических HTML. Для синхронной правки повторяющихся частей можно отредактировать `build.py` и выполнить `python3 build.py`: он обновит десять HTML и создаст папку `dist/`. Стили — `assets/site.css`; поведение — `assets/app.js`; процедурная 3D-сцена — `assets/scene.js`.

`make_standalone.py` собирает единый автономный HTML. `make_figma.py` встраивает изображения в код макетов (для запуска этого генератора нужен Pillow; готовый скрипт уже собран).

## Проверка и границы

Проверены переходы, фильтрация, сканирование, диалог, прохождение головоломки, сохранение фрагмента, три выбора, вариант без камеры, персональный финал, скачивание JSON и включение звука. Проверен автономный HTML и мобильная ширина 390 px. Прямые ссылки на отдельные страницы доступны без клиентской навигации.

Встроенный браузер проверки не поддерживает WebGL, поэтому визуальную работу объёмной модели и все 3D-сцены оригинального референса проверить не удалось. Для собственной геометрии выполнена программная проверка. Код Figma проверен на синтаксис, создание 30 фреймов и структуру в локальном тестовом окружении; в настоящем редакторе Figma он не запускался. Это отдельная адаптация визуального направления, а не подтверждённая попиксельная копия всех сцен оригинала.

Для создания кода, сценария и иллюстраций использовался ИИ. Изображения созданы специально для этой версии. Источники и библиотеки перечислены в `ASSETS.md`.
